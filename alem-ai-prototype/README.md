# Alem AI Hackathon: interactive UI prototype

Prototype of the web platform for running and AI-assisted judging of the Alem AI Hackathon.
Open `index.html` (or the GitHub Pages link) and switch between **Light** and **Dark** themes with the toggle in the top right.

Screens: login and registration, create hackathon, team application, moderation and expert assignment, assigned projects, scoring with AI summary, results and ranking, mobile views (360 px).

Direct links: `#6-scoring-ai/dark`, `#7-results/light`, and so on (`#<screen>/<theme>`).

All names, teams and scores are fictional sample data.
